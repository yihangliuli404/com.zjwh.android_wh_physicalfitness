## 校验边界

- 两份字典构造前调用 validate_totals 与 check_track：距离/时长/步数、毫秒起止、GPS 有限坐标、递增时间、累计距离及固定点覆盖。
- complete 只检查目标是否达到 selDistance/selRunTime，并非平台认证；validDis/validTime 直接赋目标值也不是独立验证结果。
- Python 类型标注不执行运行时强制校验；上述其他辅助字段未逐项做 schema 校验。
- signed URL、请求签名及真实身份关联不移植进 Android；Mock 使用另一套 testOnly DTO。
