## 发现的问题及处理

1. Java 工具最初无法直接使用云端网络/只读用户缓存：通过已有 HTTP 代理、系统受信任 Java 证书库和 `/workspace` 缓存解决，未扩大网络白名单。
2. Android 12+ 备份 Lint 提醒：为旧版 fullBackupContent 和新版 dataExtractionRules 都显式排除备份/迁移数据，最终 0 项问题。
3. 软件模拟器冷启动曾触发 System UI ANR 和 UIAutomator 空节点。等待启动稳定、降低渲染尺寸后重测；空 XML/缺失界面会失败，不绕过断言。
4. 从没有 INTERNET 权限的早期原型升级后，该模拟器虽显示权限已授予，socket 创建仍 EPERM。保留了[失败任务证据](evidence/diagnostics/mock-socket-eperm-task.json)；专用模拟器清洁安装最新 APK 后，3 项真实 Android HTTP/SQLite 仪器测试通过。不把该安装状态问题泛化为所有手机问题。
5. 仪器测试调试时发生过测试包/应用包版本不一致，随后使用 Gradle 成对构建、安装、运行并取得 3/3 通过。最终结果来自匹配的构建产物，不引用该失败轮作为成功证据。
