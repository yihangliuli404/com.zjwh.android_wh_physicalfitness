# 设备验收清单（须实测后填写）

本清单是验收步骤，不代表已经执行。已执行的项目仅以 `测试报告.md` 及证据为准。无需校园账号、Root 或第三方平台。

1. 在 Android 10+ 测试设备安装交付 APK，首次启动显示空记录，无权限弹窗及账号要求。
2. 首页添加「我的运动」、2000 米、600 秒，保存后看到 5′00″/公里；退出/强制停止再打开，记录仍在。
3. 打开记录详情，编辑标题、距离和日期；取消删除不改变数据，确认删除移除记录。
4. 模拟页生成默认样本，能看到圆形示意图、模拟标签；点击保存后在模拟筛选出现，非模拟累计不增加。
5. 工具页输入 1000 米、300 秒，应显示 5′00″/公里、12 公里/小时。空值、零或无效字符显示错误，不崩溃。
6. 详情执行本地结构校验；首页进入本地测试，运行自检并查看通过日志；清空日志不影响记录。
7. 导出 JSON/CSV 到系统下载目录，重新导入，记录数增加。模拟标签保留，其他来源为导入·未认证。
8. 标题包含中文、逗号、引号和换行的导入文件可以往返。无效表头/JSON/经纬度/时间/重复 ID 不能部分写入。
9. 在系统文件选择器取消导入、取消导出，应用继续正常工作。只读位置错误能反馈。
10. 设置浅色/深色主题，重启后保留；检查系统深色、大字体、横屏和小屏布局。
11. 飞行模式下重复上述本地功能，全部可用。仅有本机 Mock HTTP 所需的普通 INTERNET 权限，无定位、相机、通知或广泛存储申请。
12. 卸载前导出备份；卸载重装后首次为空，导入备份可恢复运动记录（测试日志与主题不包含在运动导出中）。

不得将安装/启动成功等同于全部界面验收通过。不得使用真实校园跑账号或提交任何记录。
