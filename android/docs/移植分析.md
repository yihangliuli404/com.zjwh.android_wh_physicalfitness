# Python → 原生 Android 移植分析

本阶段新增 `android/`，不删除、不修改原有 `协议/` Python 实现。Android 是独立的离线应用，不打包 Python 解释器，也不加载原始脱壳资料。

| 原模块 | 可以复用的内容 | Android 处理 |
| --- | --- | --- |
| `7.3.40/coordinate_utils.py` | 有限数、经纬度范围、共享坐标对象、边界测试思路 | Kotlin `TrackPoint`、`Fitness.coordinate` |
| `7.3.92/running/consistency.py` | 半径 6371000 米的 Haversine 距离、递增时间、距离/时长一致性规则 | Kotlin `Fitness`；不移植平台字段及分桶上报 |
| 两版既有单元测试 | 边界值、一致性、无效输入拒绝的测试思路 | 新建 JUnit 测试；原 33 项 Python 测试保留 |
| `history/models.py` | 记录结构、不要把缺失状态当成成功的原则 | 独立本地模型，全部标记为未认证，不解析平台响应 |
| `running/builder.py`、`running_protocol.py` | 仅参考本地几何计算思路 | 新写人工圆形轨迹，不复制校园打卡点规划、轨迹封装、OBS 上传或结算 |
| CLI、Python 数据类、文件读写 | 业务概念与字段 | Compose 中文界面、Kotlin 数据类、DataStore、系统文件选择器 |
| `core/client`、`sport_client`、profile/policy/history 客户端 | 依赖校园远端接口和账号状态 | 不移植校园网络接口；INTERNET 普通权限仅用于本机 Mock Server |
| login/captcha、`geetest_solver.js`、旧版 `geetest_solver.py` | 依赖 Playwright/Chromium 和外部验证码服务 | 不移植；Android 不需要 Chromium |
| telemetry、ads、平台加密与签名 | 外部埋点、广告、身份及请求协议 | 不移植 |

Python 源码不能直接作为原生 Kotlin 运行时模块复用。本次复用的是算法规范与边界条件，代码重写为 Kotlin；没有使用 Chaquopy、Termux、WebView 或浏览器。

## 外部依赖与离线范围

- 开发时：Android SDK、Gradle、Google Maven、Maven Central、Kotlin/AndroidX 库需要下载。
- 安装后：所有已实现功能可完全离线运行，包含手动记录、历史筛选、人工轨迹、配速/距离、JSON/CSV、结构校验、主题设置。
- 系统文件选择器只授权选中的文件。如果用户选择云盘提供者，云盘自身可能需要网络；本应用不具备网络权限。
- 不包含真实 GPS 采集、平台账号、校区规则同步、运动成绩校验或上传。

## 原 Android 源码检查

原仓库没有 `build.gradle`、Gradle Wrapper、`AndroidManifest.xml` 或 Java/Kotlin 应用源文件。`原始脱壳资料/运动世界7.3.93-FridaDump.zip` 内含 DEX 和 Flutter 资源，不是可直接编译的 Android Studio 工程。因此本阶段从空目录新建原生应用，未尝试重打包第三方 APK。

## 数据来源边界

- 手动记录：用户输入，标记「手动记录·未认证」。
- 模拟轨迹：人工生成，始终标记「模拟轨迹·仅本地」，首页非模拟累计不包含它。
- 导入记录：模拟标签保留；其他来源统一降为「导入记录·未认证」，重新分配本地 ID，不能导入成平台认证成绩。
- 应用不验证文件是否被外部修改；所有导入内容均不作为真实运动证明。
